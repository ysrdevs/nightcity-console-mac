The 1.9 Apple Silicon candidate is built from official upstream commit
f75df7ab817d9ffb43ea8ad84a698ad3df9ba4c1 with SIMDe submodule
e9cc73da14ab6bc2bf7c2bb4f1c2645415515d8b. The source files are unchanged.
build-kraken-macos.py records the explicit arm64/macOS 15.5 compiler target.
sources.lock.json pins the source revisions and unsigned build input hash.
This is a new source build. The previous library's historical source commit
was not recorded, and this build does not claim to reconstruct that binary.
