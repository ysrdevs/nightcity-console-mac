# Private support correction, 21 November 2026

This is an incident validation record, not a public release recommendation.

## Reported failures

Two player exports show different failures: a script-compiler constant-pool error and a native package-preparation timeout. The first export contains the 2.0.1 installed payload and the second contains 2.0.0. Both summaries incorrectly reported 2.0.0 because the launcher version was hard-coded. Receipt hashes establish the distinction.

## Changes

- The spawned child process receives an empty signal mask. The parent background worker previously passed a blocked SIGCHLD signal to the .NET preparation helper, which then waited indefinitely for its completed child. The caller's signal mask is unchanged.
- Child process waiting, pipe errors, deadlines and bounded preparation logs now distinguish preparation failures instead of hiding them behind a timeout.
- The script compiler defers added fields until their new target and ancestor declarations are available. Existing resolved declarations retain their original path; inherited duplicate-field validation is retained. This fixes a reproduced order-dependent constant-pool error. The player's exact definition number has not been mapped because the export did not contain their script contents.
- Diagnostics include bounded preparation/native game logs, compiler and cache hashes, and the actual running bundle version.
- Valid AppleDouble sidecars in compiler hints are removed using the existing guarded cleanup. This addresses a secondary hint-reading error, not the primary compilation failure.

## What has been tested locally

The actual published preparation helper reproduced the original 120-second background timeout. With the child signal-mask correction, it completed three repeated checks in under a quarter second. The released compiler also completed from the corrected background runner.

A disposable installation starting with published 2.0.1 payload files and its exact receipt passed 63 integration assertions: replacement and backup, edited-file refusal, interrupted-update rollback, preservation of concurrent external edits, reinstalling a deleted compiler pair, and the actual preparation and compile components. The game executable identity in this fixture is synthetic; it does not test game launch or the launcher UI.

The corrected compiler passed 75 compiler/core tests, formatting, Clippy and 17 actual compiler API cases. Independent review identified and corrected an inherited-field conflict before the final candidate.

Copies of the 234 installed scripts were compiled using the production layout: 217 normal scripts and 17 separate runtime scripts. The original stock cache remained unchanged. That output reached the real game's title screen, initialized Native Settings, connected the native Console frontend and exited with status 0. No save was loaded and no gameplay was tested in this support check. The unchanged ITP module logged caught shutdown diagnostics after bindings retired; the session is not described as having completely clean logs.

An earlier test flattened both script roots into one directory and reversed the wrapper order. Both original and corrected compilers then failed the Native Settings startup check. That fixture was invalid for the production launch path and was corrected. No runtime validation was bypassed.

The private candidate starts from the exact published 2.0.1 application. Before signing, only its launcher, bundle identity/version, native compiler pair and native payload inventory differ. Runtime/framework binaries, mod scripts and legacy compatibility resources remain unchanged. The inventory retains the exact previous published hashes for upgrades.

Signing, notarization and stapling establish packaging properties only. They do not establish player compatibility. Local fixture and startup results do not establish that either affected player's installation now works. No affected-player acceptance or support-candidate gameplay acceptance has been obtained. No public release or push is authorized by this record.
