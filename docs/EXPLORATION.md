# Noclip flight

Noclip is available in NightCity Console 1.8 on **Cyberpunk 2077 2.5.0, native macOS Steam**. Open **F1 → Exploration** to use it. The launcher installs its scripts with NightCity Console; no separate mod download is needed.

## Start and move

Stand or crouch on clear ground, click **Start**, then close F1. Preparation is automatic. You do not need to click Validate flight or crouch first.

| Input | Action |
| --- | --- |
| W / A / S / D | Move relative to the camera |
| Mouse | Look around |
| Space | Move up |
| Control | Move down |
| Shift | Boost to 12 metres per second |
| Alt / Option | Precision movement at 0.75 metres per second |

Use **Flight speed** to choose Slow, Normal, Fast or Faster. On a Windows-style keyboard connected to a Mac, **Alt** is the Option key.

Flight can pass through geometry and travel beyond the starting area. It has no automatic time limit or return radius. Clicking Start during an active flight does not stop it.

## Stop at your destination

Move over clear ground or a clear rooftop, then descend until your feet are just above its surface. Open F1 and click **Stop here**. Normal collision and gravity resume at that position, so stopping high above a surface makes the player fall.

If there is not enough room for the standing player, Stop here keeps flight paused. Choose **Resume**, close F1, release the movement keys and move into open space before trying again.

**Return to start** is optional. It returns to where the current flight began, if that position is still clear, and restores normal collision. You can start a new flight afterward. It does not return to an earlier save or to the start of a previous flight.

Stop flight and confirm normal walking before saving.

## Menus and interactions

- Opening F1 holds movement while you use the controls.
- Opening Inventory or switching apps pauses flight in place. Close menus, choose **Resume**, then close F1 and release movement keys to continue.
- Using a computer or entering a supported workspot stops flight as the game takes control. Finish the interaction and use **Start** again from clear ground.
- Jump, scanner and dash controls retain their normal behavior after flight ends. During flight, Space controls ascent and Control controls descent.

The game can interrupt flight when it takes control of the player. Noclip does not bypass quest requirements, load distant interiors on demand or make an obstructed destination safe.

## If flight refuses to start or stop

Click **Check flight status** once and read the result in the Console tab. A blocked stop needs open space. A return that is still waiting for arrival must finish before another flight can start.

If a refusal persists, leave the game running and export a diagnostics ZIP from the launcher before reloading. Include the action you used just before the problem and whether you were near a wall, using a computer or switching menus. **Validate flight** and **Record camera input** are optional troubleshooting controls, not startup requirements.

Noclip requires the supported 2.5 build. The existing console remains available on 2.3.1, but flight is not installed there.
